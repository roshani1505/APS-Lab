# APS-Lab

All programs of **Algorithms and Problem-Solving (LAB)**.

This repository contains a series of Jupyter notebooks covering foundational algorithm design and analysis topics, ranging from basic algorithmic building blocks to advanced graph and dynamic programming problems.

## Contents

### `Lab_1_AlgorithmsBasics.ipynb` — Algorithm's Basics
Introduces the concept of an algorithm and walks through classic introductory problems:
- Greatest Common Divisor (GCD) — simple and enhanced (Euclidean) approaches
- Fibonacci Series — recursive, iterative, and approximation approaches
- Integer Factorization
- Tower of Hanoi — recursive/classic and iterative algorithms
- Sorting Algorithms (with before/after plotting of sorted data)
- Includes references to Wikipedia articles for each topic

### `Lab_2_AlgorithmsBasics.ipynb` — Algorithm's Basics (continued)
Covers foundational problem-solving concepts:
- Problem Definition
- Arrays

### `Lab_3_Growth_of_function.ipynb` — Growth of Function
Explores asymptotic complexity classes with explanations and plotted graphs:
- Constant Time Complexity — O(1)
- Linear Time Complexity — O(n)
- Logarithmic Time Complexity — O(log n)
- Log-Linear Time Complexity — O(n log n)
- Polynomial Time Complexity — O(n^c)
- Exponential Time Complexity — O(c^n)

### `lab_4.ipynb` — Searching
Implements and analyzes searching algorithms, including additional practice problems (Prob-3, Prob-4).

### `Lab_5.ipynb` — Divide and Conquer (Sorting)
Implements divide-and-conquer sorting algorithms and includes an experiment comparing the performance of different sorting algorithms.

### `Lab_6.ipynb` — Divide and Conquer (Sorting)
Continuation of divide-and-conquer sorting techniques and their analysis.

### `Lab_7.ipynb` — Greedy Knapsack Problem (Fractional)
Covers the Fractional Knapsack Problem using a greedy approach:
- Problem Definition
- Pseudocode and implementation

### `Lab_8.ipynb` — Minimum Cost Spanning Tree
Implements algorithms to find the Minimum Cost Spanning Tree of a graph.

### `Lab_9.ipynb` — Shortest Path Using Dijkstra's Algorithm
Explains the theory and algorithm steps for Dijkstra's shortest path algorithm, along with its Python implementation.

### `Lab_10.ipynb` — Warshall's Algorithm & All-Pairs Shortest Path
Covers:
- Warshall's Algorithm to determine reachability between all pairs of vertices in a graph
- Floyd-Warshall Algorithm to find shortest paths between all pairs of vertices
- Dynamic programming approach to the all-pairs shortest path problem
- Exercises for practice

### `Lab_11.ipynb` — Travelling Salesman Problem (Dynamic Programming)
Covers the theory, algorithm, and implementation of solving the Travelling Salesman Problem using a dynamic programming approach, along with exercises.

### `Lab_12.ipynb` — Matrix Chain Multiplication (Dynamic Programming)
Covers the theory, algorithm, and table-filling technique for solving the Matrix Chain Multiplication problem using dynamic programming, along with exercises.

## Topics Covered Overall
- Algorithm fundamentals (GCD, Fibonacci, factorization, Tower of Hanoi)
- Growth of functions / time complexity analysis
- Searching algorithms
- Divide and conquer (sorting algorithms)
- Greedy algorithms (Fractional Knapsack)
- Graph algorithms (Minimum Spanning Tree, Dijkstra's, Warshall's, Floyd-Warshall)
- Dynamic programming (All-Pairs Shortest Path, Travelling Salesman Problem, Matrix Chain Multiplication)

## Usage
Each notebook can be opened directly in Jupyter Notebook/JupyterLab or Google Colab (several notebooks include an "Open in Colab" badge). Notebooks generally require standard Python scientific libraries such as `numpy`, `scipy`, `matplotlib`, and `statistics`.
